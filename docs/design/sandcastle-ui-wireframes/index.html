sandcastle ui — wireframes

Flat HTML stubs for the v1 surface. Review artefacts, not production code. Component library locked in: Radix UI. Build tool: Vite.

Live session view
Iteration timeline, tool-call cards (collapsed + expanded), live metrics row, commit sidebar. Includes autopilot-ON state and config-changed badge.
Live session — halted
Same chrome, halted state: autopilot OFF, halt banner with Resume, errored final session header, retry CTA, hit-max-iterations failure detail.
File diff viewer
Per-commit file tree on the left, side-by-side diff pane with unified toggle. Linked from any file in the commit sidebar.
Queue view
JIRA TODO list in autopilot pickup order, label chips, "Run now" / "Run with overrides…" per row.
Manual-mode override sheet
Modal sheet over the queue: scenario, model, max iterations, freeform promptArgs JSON. Overrides apply only to this invocation.
History list
Ticket-bounded sessions with outcome badges (done / errored / halted), per-row metrics, inline error detail, retry CTA on failed rows, status filter chips.
Ticket detail
Per-ticket aggregates (sessions, total wall time, avg iterations, total commits, total tokens) + every session for that ticket.
